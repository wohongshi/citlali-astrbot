# 茜特菈莉 AI Agent — AstrBot 完整方案

原神角色「茜特菈莉（黑曜石奶奶）」的 AI Agent 人格系统，基于 AstrBot 平台。

## 功能特性

### 🎭 角色人格
- 完整的茜特菈莉人格设定（system prompt）
- 12个知识库文件覆盖世界观、故事、台词、传说任务
- 6阶段好感度系统（陌生人→熟人→朋友→好友→知己→旅行者）

### 🧠 自包含记忆引擎
- Embedding 向量检索（调用 AstrBot Embedding Provider）
- BM25 文本检索（中文 bigram 分词）
- 混合检索（40% BM25 + 60% 向量，RRF 融合）
- 自动对话总结（调用 LLM）
- 记忆图谱（实体+关系）
- 时间衰减 + 访问强化

### 🌙 日程时段系统
- 5个时段自动切换语态（深夜/早晨/中午/下午/晚上）
- 特殊日期触发（新年、情人节等）
- 天气联动
- 时段敏感的特殊回复（喝酒、小说、占卜等）

### 💕 好感度系统
- 自动检测对话内容增加好感度
- 关系阶段升级触发角色回应
- 每日衰减机制
- WebUI 可视化管理

### 🖥️ 完整 WebUI
- 总览：用户数、记忆数、图谱节点、当前时段
- 用户管理：搜索、排行、详情、手动调整
- 记忆检索：关键词搜索
- 记忆图谱：Canvas 力导向可视化
- 配置查看

## 部署步骤

### 1. 配置 Embedding Provider
在 AstrBot WebUI 中添加 Embedding Provider（推荐硅基流动 BAAI/bge-m3）

### 2. 设置人格
将 `persona/system_prompt.md` 的内容粘贴到 AstrBot 的人格配置中

### 3. 上传知识库
在 AstrBot WebUI 中创建知识库，上传 `knowledge_base/` 下的 12 个 .md 文件

### 4. 安装插件
将 `plugin/` 目录复制到 `data/plugins/citlali_affinity/`，重启 AstrBot

### 5. 配置插件
在 AstrBot WebUI 的插件配置中设置 Embedding Provider ID 和 LLM Provider ID
