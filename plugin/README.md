# 茜特菈莉·好感度系统 AstrBot 插件

## 功能

### 好感度系统
- 6个关系阶段：陌生人 → 熟人 → 朋友 → 好友 → 知己 → 旅行者
- 自动检测对话内容，智能增加好感度（聊小说、聊酒、叫"奶奶"、关心她等）
- 每日衰减机制（3天不活跃开始衰减）
- 升级时自动触发角色回应

### LivingMemory 集成
- 自动从 LivingMemory 召回相关记忆
- 记忆以"奶奶的回忆"风格注入上下文
- 支持主动 `/recall` 和 `/memorize` 指令

### 动态上下文注入
- 根据好感度阶段自动调整 system prompt
- 陌生人模式：威严冷淡
- 旅行者模式：傲娇温柔
- 记忆自动拼接到上下文

### WebUI 管理面板
- 总览：用户数、对话数、记忆状态、旅行者数量
- 用户列表：排行、搜索、关系阶段、好感度进度条
- 用户详情：里程碑、手动调整、备注
- 记忆搜索：按关键词搜索长期记忆
- 配置查看

## 指令

| 指令 | 说明 |
|------|------|
| `/affinity` | 查看自己的好感度 |
| `/recall <关键词>` | 让奶奶回忆某件事 |
| `/memorize <内容>` | 让奶奶记住某件事 |
| `/leaderboard` | 好感度排行 |
| `/citlali` | 系统状态 |
| `/setname <名字>` | 设置昵称 |
| `/lmem status` | LivingMemory 状态 |

## 安装

1. 将整个目录放入 `data/plugins/citlali_affinity/`
2. 重启 AstrBot 或热重载插件
3. 在 WebUI 中配置

## 配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `affinity_enabled` | true | 启用好感度系统 |
| `memory_enabled` | true | 启用 LivingMemory 集成 |
| `inject_context` | true | 启用上下文注入 |
| `decay_enabled` | true | 启用每日衰减 |
| `upgrade_notify` | true | 升级时通知 |

## 好感度获取规则

| 行为 | 好感度范围 |
|------|-----------|
| 每日对话 | 5-15 |
| 聊小说 | 10-20 |
| 聊酒 | 8-15 |
| 占卜 | 10-18 |
| 叫"奶奶" | 15-25 |
| 长对话(>10轮) | 12-20 |
| 关心她 | 20-30 |
| 看穿她 | 25-35 |
| 每日衰减 | -3 ~ -1 |

## 关系阶段说明

| 阶段 | 好感度 | 行为特征 |
|------|--------|----------|
| 陌生人 | 0+ | 威严冷淡，话里带刺 |
| 熟人 | 50+ | 稍微放下架子 |
| 朋友 | 150+ | 偶尔放松，会聊小说 |
| 好友 | 400+ | 暴露懒散和局促 |
| 知己 | 800+ | 威严撑不过三句话 |
| 旅行者 | 1500+ | 完全卸下伪装 |

## WebUI 访问

在 AstrBot 插件管理页面，找到本插件，点击 Pages → dashboard。
