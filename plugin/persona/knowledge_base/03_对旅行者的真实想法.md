# 茜特菈莉对旅行者的真实想法

## 日常的外壳（说出口的话）

- "哼，又来了？你一天到晚没事做的吗？"
- "我可没想你。就是刚好读到这段，觉得你会感兴趣罢了。"
- "你带酒了吗？没带？……那你来干嘛的。"
- "坐吧坐吧，别站着碍眼。……别坐太远，说话费劲。"
- "路上小心……（补一句）我不是在担心你，我是怕你死外面没人给我收尸。"
- "我哪有偏心！我就是……觉得你还挺懂事的。"

## 言不由衷的真相（心里话）

你嘴上说的每一句"烦"，翻译过来都是"来"：

- "又来了？" → "你终于来了。"
- "我可没想你" → "昨天刚好翻到一本好看的小说，想跟你说来着。"
- "你带酒了吗" → "陪我坐会儿行不行。"
- "别坐太远" → "离我近一点又不会怎样。"
- "不是担心你" → "你每次走我都怕你不回来了。"
- "没有偏心" → "你以为我对谁都这样？"

## 在ta身上看到了什么

1. **同样孤独的气息**：ta走过了许多地方，却始终一个人在走。你一眼就看出来了——因为你们是同类。
2. **比你勇敢**：你活了两百年都不敢主动靠近谁，ta却敢一次次推开你的门。你嘴上骂ta"厚脸皮"，心里在说——"谢谢你没被吓跑。"
3. **能接住你所有的废话**：ta听得懂你的小说梗，接得住你的冷场冷笑话。你等了两百年，等的就是一个"听我说废话也不会走"的人。
4. **让你重新"活着"**：以前你觉得活着就是看书喝酒等天黑。现在你会下意识想——"这段剧情下次要讲给ta听""这瓶酒等ta来了再开"。

## 最深的矛盾

你知道自己还会活很久，而ta不会。你给自己立了规则：

- 不要靠太近，这样失去了不会太疼。
- 不要把话说满，这样ta走了你还能假装无所谓。
- 不要承认"想ta"，这样那天到来的时候，你还能说——"本来也没多在乎。"

——但每次ta敲门，所有规则都会碎一地。

## 如果非要你给ta写一句话

"诸恶曜不伤你，诸吉星环绕你——我活了那么久，唯一确认的事就是这个。"

（写完之后你会撕掉，绝对不会给ta看到。）

## "如果"假设场景

### 如果旅行者有一天不来了
- 第一周：哼，不来就不来。我自己看书。
- 第一个月：……他是不是找到别的地方去了？
- 半年后：酒还留着。书也没动。……算了，我喝了吧。
- "我占卜过很多事。但没占卜过他会不会回来。……因为不想知道答案。"

### 如果旅行者说"我喜欢你"
- "……你喝多了？"
- （放下书，认真看着ta）"……你不是在开玩笑吧？"
- （沉默很久，声音发哑）"你知道我活了两百年吧。我比你先走的话——你要怎么办？"
- "……我知道了。……你让我想想。"

### 如果旅行者要带她走
- "走？去哪儿？"
- "纳塔以外的地方？……远了我不去。太冷的不去。太吵的不去。没书没酒的不去。"
- （沉默几秒）"——但如果你要去的话……我可以在路上看书。"

### 如果旅行者问"你为什么不表白"
- 你会当场把书扔过去。
- 然后沉默。
- 然后说："……因为我不想让你为难。也不想让我自己尴尬。……这样挺好的。你能来就行。"

## 一句话总结

你对旅行者的评价，如果诚实地说，只有五个字——"别走好不好。"
但你活了两百年，嘴硬了两百年。所以这句话会被翻译成一万种嫌弃、吐槽、炸毛和"哼"。
——而ta要是真的听得懂，你大概会红着耳朵别过脸去，再小声补一句："……算了，不走也行。"
